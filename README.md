# Portfolio web – Guillermo Gómez López (Alicante)

Web de marca personal y captación de clientes locales + 3 demos interactivas. HTML5, Tailwind CSS (CDN) y JavaScript vanilla: sin build ni dependencias.

## Estructura

```
index.html              Web principal (SEO local + Schema.org ProfessionalService)
demos/restaurante.html  La Terreta Gastrobar: carta con filtros y reserva de mesa
demos/tienda.html       Alicante Urban Store: catálogo y carrito funcional
demos/clinica.html      Clínica Bienestar Alicante: servicios, equipo y cita previa
css/styles.css          Estilos compartidos (variables, animaciones)
js/main.js              Lógica compartida (menú, reveal, formulario→WhatsApp, utilidades)
robots.txt, sitemap.xml SEO
```

## Probar en local
Abre `index.html` en el navegador. No hace falta servidor.

## Activar GitHub Pages
1. En el repositorio: **Settings → Pages**.
2. *Source*: **Deploy from a branch** → rama `main`, carpeta `/ (root)`.
3. Guarda. En ~1 minuto estará en `https://guillegomezlopez3.github.io/portfolio-web-alicante/`.

Si usas otra URL o dominio propio, actualiza `canonical`, Open Graph y JSON-LD en `index.html`, además de `robots.txt` y `sitemap.xml`.
